# AI Tools

This directory contains setup guides and installation scripts for various AI-related tools, organized by category.

## Categories

### [Speech & Dictation](speech/)

Tools for speech recognition, text-to-speech, and dictation:

- **[OpenAI Whisper](speech/whisper/)** - Local speech-to-text recognition
- **[Voice Mode](speech/voice-mode/)** - Voice interface for Claude Code
- **[Dictation Setup](speech/dictation/)** - General dictation configuration for Ubuntu

### [LLM (Large Language Models)](llm/)

Tools for running and integrating large language models:

- **[Local Deployment](llm/local-deployment/)** - Run LLMs locally (Ollama, LocalAI, vLLM)
- **[Claude Code Integration](llm/claude-code/)** - Integrate LLMs with Claude Code

### [Productivity](productivity/)

Additional AI-powered productivity tools (coming soon)

## Quick Navigation

Use the main setup script to access these tools interactively:

```bash
cd ..
./setup.sh
```

Or navigate directly to specific tool documentation in the subdirectories above.
